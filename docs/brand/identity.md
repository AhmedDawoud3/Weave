# Weave Brand Identity & Guidelines

Welcome to the official brand guidelines for Weave. This document outlines Weave's core identity, positioning, voice, style, visual aesthetics, and core messaging pillars. Use these guidelines to ensure consistency across the product, marketing, and community assets.

---

## 1. Core Identity & Tagline

* **Official Name:** Weave
* **Primary Slogan:** *"Design the Architecture. Ship the Code."*
* **Alternative Tagline:** *"Visual Deep Learning. Direct to PyTorch."*

---

## 2. Positioning Statement

> For ML practitioners who are tired of boilerplate code and slow iteration cycles, Weave is the modular neural network editor that transforms visual architecture design into production-ready PyTorch code — instantly. Unlike generic no-code tools, Weave is built with engineering rigor and design sophistication, giving you full control without sacrificing speed.

---

## 3. Brand Voice & Style

Weave speaks with the **confidence of a seasoned ML engineer** and the **clarity of a great technical writer** — precise, direct, and free of fluff. 

* **Respectful & Intelligent:** We respect our users' intelligence and deep technical backgrounds. We do not oversimplify complex concepts or use patronizing terms.
* **Problem-Focused:** We speak directly to real-world pain points like shape debugging, boilerplate overhead, and system integrations.
* **Craft-Celebrating:** We celebrate the craft and engineering behind building elegant, optimized deep learning architectures.
* **Tone Do's & Don'ts:**
  * **Do:** Write concisely, use accurate deep learning terminology (e.g., "dimension inference", "tensor flow", "convolutional channels"), and show code examples.
  * **Don't:** Use hyperbolic marketing buzzwords ("magic", "revolutionize", "disrupt") or pretend that visual design completely replaces coding.

---

## 4. Visual Aesthetic

Weave features a premium, developer-centric, **dark-mode-first aesthetic** built on high-contrast accent paths.

* **Primary Backgrounds:** Anchored in a deep near-black navy (`#0D0F1A`), projecting technical depth, focus, and reduced eye strain during long coding sessions.
* **Accents & Flow:** A distinctive electric teal (`#00E5C4` / `#2DD4BF`) represents signal flow and active nodes, providing an ownable, energetic highlight that differentiates Weave from traditional cold blues and purples.
* **Typography:** Uses a clean, geometric sans-serif (e.g., **Inter** or **Geist**) for UI and marketing copy, combined with a bold, technical, and confident wordmark.
* **Iconography:** Draws inspiration from:
  * Node graphs and connection sockets
  * Interwoven connector threads (referencing the "weave" metaphor)
  * Circuit-like lattices and structured matrix grids
* **Interactions:** Dynamic canvas animations, smooth gradient glows under active nodes, and flowing connection lines representing computational data paths.

### 5.1 Contrast & UX Accessibility

To ensure Weave remains highly accessible and professional:
* **Background-to-Text Contrast:** Text colors used on top of the `#0F1117` slate background should be pure white (`#FFFFFF`) or high-contrast silver (`#E2E8F0`), maintaining a high contrast ratio exceeding **WCAG AAA** recommendations for text readability.
* **Component Layering:** To keep node elements distinguishable on the canvas, use distinct gray/slate borders (such as `#1E293B`) or semi-transparent backdrops (`rgba(15, 17, 23, 0.8)`) instead of pure high-contrast borders, preserving visual calm.
* **Visual Port Signaling:** The bright colors (`#1ABCFE`, `#2DD4BF`, `#F97316`) have a high luminance contrast against the dark background. Sockets, input ports, and active edges are instantly visible even at high zoom-out levels.
* **Color Blindness Adaptability:** Do not rely solely on color to convey state. The Amber (`#F97316`) diagnostic warnings should always be accompanied by icons (e.g., alert triangles ⚠️) and helpful tooltips to ensure colorblind developers (deuteranopia/protanopia) can debug easily.

## 6. Personality Traits

Weave is defined by five core personality traits:

1. **Precise:** In our terminology, our code generation, and our user interface.
2. **Empowering:** Giving control back to the developer, assisting without taking away flexibility.
3. **Sophisticated:** High-quality aesthetic design that makes developers feel like they are working in a premium workspace.
4. **Credible:** Built on robust, correct compiler behavior and standard PyTorch implementations.
5. **Innovative:** Moving beyond static drawing tools to create an interactive design-to-code compiler.
