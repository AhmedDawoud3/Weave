WEAVE Logo Package

This folder contains all official WEAVE logo assets optimized for web,
application, and presentation use.

Source File

-   Logo_Master.ai — Editable Adobe Illustrator source file.

Primary Logo Variations

-   logo_horizontal_FullColor.svg / .png — Main colored logo for
    websites and documents.
-   logo_horizontal_FullColor_txt_Black.svg / .png — Colored icon with
    black text for light backgrounds.
-   logo_horizontal_FullColor_txt_Gray.svg / .png — Colored icon with
    gray text for modern UI designs.

Stacked Logo Variations

-   Logo_Stacked_FullColor.svg / .png — Vertical version for
    presentations and narrow layouts.
-   Logo_Stacked_FullBlack.svg / .png — Black version for monochrome
    printing and light backgrounds.
-   Logo_Stacked_FullGray.svg / .png — Gray version for secondary
    branding.
-   Logo_Stacked_FullWhite.svg / .png — White version for dark
    backgrounds.

Icon Variations

-   Logo_IconOnly.svg / .png — Icon-only version for avatars, app icons,
    and compact UI elements.

Favicon Files

-   favicon_(16x16).png / .ico — Standard browser tab icon.
-   favicon_(32x32).png / .ico — Recommended favicon size for modern
    browsers.
-   favicon_(48x48).png / .ico — High-resolution favicon for desktop
    shortcuts and legacy support.

Recommended Usage

-   Horizontal Full Color — Website header and primary branding.
-   Stacked Full Color — Presentations and posters.
-   Icon Only — Favicon, mobile app icon, social media profile.
-   Black Version — Printing and light backgrounds.
-   White Version — Dark backgrounds.
-   SVG Files — Websites and scalable graphics.
-   PNG Files — General use and presentations.
-   AI File — Future editing and modifications.
